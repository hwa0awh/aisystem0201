# 🎤 SKOACH
> speak + coach — 발표 준비의 모든 과정을 AI와 함께

## 서비스 소개
SKOACH는 발표가 두려운 사람들을 위한 AI 발표 코칭 서비스입니다.
PPTX·PDF를 업로드하거나 가이드라인을 작성하면 AI가 발표 대본을 자동으로 생성하고,
대본을 업로드하면 발음 코칭부터 음성 평가까지 발표 준비의 전 과정을 한 번에 해결합니다.

## 핵심 기능
- 📄 **AI 대본 생성** — PPT·PDF 업로드 또는 가이드라인 입력으로 슬라이드별 대본 자동 생성
- 💬 **발음 코칭** — 표기-발음 불일치·연음·장단음 단어를 색상으로 구분해 표시
- 🎙 **발음 평가** — 음성 파일 업로드 후 AI가 원본 대본과 비교해 0~5점 채점
